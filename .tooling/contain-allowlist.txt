# contain-allowlist.txt — backstop allow-list for .tooling/bin/contain-snapshot (plan §9.4 b)
#
# Lines: "allow <glob> # reason"  or  "collision <glob> # reason"
# Globs are shell `case` patterns relative to $HOME ("*" also matches "/"). No spaces inside a glob;
# use "?" for a space. Only paths written by the OS, by the Manager's own apps, or by the Claude Code
# harness belong here. Nothing our tools write may ever be listed.
#
# "collision" = a macOS/third-party path whose NAME contains a project-tool token (e.g. Apple's
# "Biome" framework vs the Biome linter). It exempts that path from the tool-name hard fail and
# must name the unrelated owner.
#
# Scope note (audit A-1): a trailing "*" matches the whole subtree, deliberately. This is safe only
# because classification is hard-fail-first: any path whose name contains a project-tool token
# fails before the allow list is consulted. Entries are added only for churn actually observed
# (fail closed); unobserved speculative entries such as Keychains and Xcode were removed.
